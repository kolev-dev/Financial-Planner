# Financial Planner Web - Контейнеризация с Docker Compose

Проекта представлява финансово приложение, което е напълно контейнеризирано с Docker и Docker Compose.

---

## 1. Структура на проекта

```
Financial-Planner/
├── actions/
│   └── add_goal.php
├── includes/
│   └── db.php
├── **compose.yml**
├── **Dockerfile**
├── databaseInstallation.sql
├── financial_planner_dump.sql
├── README.md
└── [останалите .php файлове]
```

---

## 2. Компоненти на системата
Проектът се състои от два отделни и изолирани компонента (услуги):
* **financial-planner-web (Бекенд/Уеб сървър):** Основното приложение, което съдържа бизнес логиката. Изгражда се чрез персонализиран `Dockerfile`.
* **mysql (База данни):** Официален образ на MySQL сървър, където се съхраняват и структурират всички потребители и техните данни.

---

## 3. Комуникация между услугите
Комуникацията между уеб приложението и MySQL базата данни е осъществена чрез вградената изолирана виртуална мрежа (Bridge Network), която Docker Compose създава автоматично при стартиране.

Вместо да използва адреса `localhost` (който в контейнера сочи към самия контейнер), приложението се свързва към базата данни, използвайки **името на услугата** от `compose.yml` файла като хост (Host: `mysql`). По този начин Docker вътрешно превежда името на услугата до правилния IP адрес на контейнера с базата данни.

---

## 4. Как се изграждат и стартират контейнерите

### Изисквания:
* Инсталиран Docker Desktop (за Windows) или Docker Engine с Docker Compose (за Linux).

### Инструкции за стартиране:
За да изградите образите от сорс кода и да стартирате целия проект заедно с базата данни, изпълнете следната команда в коренната директория на проекта:


(Изграждане с --build ще изтрие стари гененерирани образи и пак ще ги изгради.)
```
docker compose up --build
```

След като контейнерите стартират успешно, приложението ще започне да функционира напълно и ще бъде достъпно в браузъра, като въведете в адресното поле ```localhost:8080```.

За спиране на контейнерите и изчистване на виртуалната мрежа, използвайте:
```
docker compose down
```
